# vpauls.github.io

This is a GitHub Pages user site. The site will be published at:

https://vpauls.github.io

How to update
1. Edit `index.html` (or add other files).
2. Commit and push to the `main` branch (or whichever branch you set as Pages source).
3. In the repository -> Settings -> Pages confirm the source is `main` / root.

Notes
- The repository name must be exactly `vpauls.github.io`.
- For public access make the repo Public.
- If you want a custom domain, add a `CNAME` file with the domain and configure DNS.
